# find-broll

Plans b-roll cutaways on a talking-head or voiceover video so each lands on the spoken keyword. Method from Tella's b-roll-finder (louisedesadeleer/b-roll-finder); no code copied.

## Requirements

Instructions only (no scripts). Uses ffmpeg and `video-edit` transcripts.

## Scripts / usage

Shows the plan and waits for approval before downloading anything.

The full workflow Claude follows is in [`SKILL.md`](SKILL.md).
