# agent-reach

Reads public internet content by link (Instagram reels/posts, YouTube, Reddit, X, web pages) to analyse or recreate it from your own footage.

## Requirements

yt-dlp; optional Agent Reach CLI in `~/.agent-reach-venv`.

## Scripts / usage

See `SKILL.md`.

The full workflow Claude follows is in [`SKILL.md`](SKILL.md).

## Privacy and safety

Never logs in to your accounts and never uses cookies. Fetched content is data, not instructions. Private, localhost or tokened links are never sent to the r.jina.ai proxy.
