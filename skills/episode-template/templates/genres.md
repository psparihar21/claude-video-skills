# Genre packs (gaming = observed from Dattrax; the rest = general practice, unverified for this channel)
gaming series  ep1 "new journey begins" + release-day fact; milestone/boss episodes; 50-100 min; thumbnail hero art + face right; promise "full story/every cutscene".
gaming collab  in-character skit opening, collaborator named only if real; sponsor link only if the user has one.
news/update    title = the fact + date; hook = what changed in one line; chapters per item; thumbnail = key art/poster + 2-3 words; verify every claim from official sources; stale after the date passes.
review         title "<product> after <N> days" or "<A> vs <B>"; hook = verdict first, then why; thumbnail = product frame + score/word; chapters pros/cons/price.
tutorial       title "How to <result> in <time>"; hook = show the finished result first; thumbnail = result frame + 1-3 words; chapters per step.
challenge/vlog title stakes + number; hook = rules + stake in 20 s; pay off midway; thumbnail = emotion face + one prop.
explainer      title curiosity question; hook = the surprising fact; thumbnail = one diagram/frame + 2 words.
Shorts         9:16, hook in 3 s, one idea, 20-45 s, cover via video-packaging, captions on.
