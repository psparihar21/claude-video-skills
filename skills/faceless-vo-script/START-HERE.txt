Using faceless-vo-script outside Claude Code (claude.ai Projects)

1. Download or clone the repo and open skills/faceless-vo-script/.
2. In Claude, open a Project (or a chat that accepts files).
3. Upload every file in the faceless-vo-script folder. Keep the folder names: references, scripts, assets, evals.
4. Open PASTE-INTO-CLAUDE.md and paste everything under the line into the Project instructions, or into your first message.
5. Then send Claude your locked edit (shot list, timeline, or video).

In Claude Code, skip all of this: run install.ps1 from the repo root, or copy this folder to ~/.claude/skills/.
